# ADR 0011: Servidor propio como alternativa futura a Railway

- Estado: aceptada
- Fecha: 2026-10-15
- Origen: sección 9 del documento maestro

## Decisión

Servidor propio como alternativa futura a Railway.

## Motivo

Solo si el costo o el control lo justifican.

## Alternativa descartada

Migrar antes de tener clientes.
