# ADR 0003: FastAPI en Railway para la lógica de negocio

- Estado: aceptada
- Fecha: 2026-10-15
- Origen: sección 9 del documento maestro

## Decisión

FastAPI en Railway para la lógica de negocio.

## Motivo

Dominio previo del fundador; Python es adecuado para cálculo, PDF e importación de planillas.

## Alternativa descartada

Lógica en funciones de Supabase o en Next.js.
