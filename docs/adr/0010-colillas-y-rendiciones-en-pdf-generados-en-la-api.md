# ADR 0010: Colillas y rendiciones en PDF generados en la API

- Estado: aceptada
- Fecha: 2026-10-15
- Origen: sección 9 del documento maestro

## Decisión

Colillas y rendiciones en PDF generados en la API.

## Motivo

Un solo lugar para el formato legal del aviso de cobro.

## Alternativa descartada

PDF en el navegador.
