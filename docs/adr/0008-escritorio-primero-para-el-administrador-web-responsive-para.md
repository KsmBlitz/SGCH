# ADR 0008: Escritorio primero para el administrador; web responsive para residentes, sin app nativa

- Estado: aceptada
- Fecha: 2026-10-15
- Origen: sección 9 del documento maestro

## Decisión

Escritorio primero para el administrador; web responsive para residentes, sin app nativa.

## Motivo

El administrador opera en PC; el residente solo consulta.

## Alternativa descartada

App nativa desde el inicio.
