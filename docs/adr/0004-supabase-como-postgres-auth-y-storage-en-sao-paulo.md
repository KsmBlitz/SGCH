# ADR 0004: Supabase como Postgres, Auth y Storage, en São Paulo

- Estado: aceptada
- Fecha: 2026-10-15
- Origen: sección 9 del documento maestro

## Decisión

Supabase como Postgres, Auth y Storage, en São Paulo.

## Motivo

Reduce infraestructura; RLS nativo; latencia baja desde Chile.

## Alternativa descartada

Postgres propio.
