# ADR 0001: Monorepo con apps/web, apps/api y supabase/

- Estado: aceptada
- Fecha: 2026-10-15
- Origen: sección 9 del documento maestro

## Decisión

Monorepo con apps/web, apps/api y supabase/.

## Motivo

Un solo contexto para el fundador y para la IA en Cursor.

## Alternativa descartada

Repositorios separados.
